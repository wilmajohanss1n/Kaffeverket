# Kaffeverket
Kaffeverket är en fiktiv webbplats för ett cafe som erbjuder kaffe, matcha, fika och lättare måltider. Syftet med Kaffeverket är att göra det enkelt för besökare att hitta menyn, öppetider och kontaktuppgifter. 

Webbplatsen är utvecklad med HTML, CSS och JavaScript samt är anpassad för både mobil och dator.

## Publicerad webbplats
https://kaffeverket.netlify.app/
