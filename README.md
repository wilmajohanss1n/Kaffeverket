# Kaffeverket
Kaffeverket är en fiktiv webbplats för ett cafe som erbjuder kaffe, matcha, fika och lättare måltider. Syftet med Kaffeverket är att göra det enkelt för besökare att hitta menyn, öppetider och kontaktuppgifter. Målgruppen är unga vuxna, exempelvis studenter. Webbplatsen är utvecklad med HTML, CSS och JavaScript samt är anpassad för både mobil och dator.

## Tekniker och verktyg
* HTML - webbplatsens struktur och innehåll
* CSS - desgin, layout och responsiv anpassning
* JavaScript - interaktiva funktioner
* Git och GitHub - versionshantering och lagring av projektet
* Figma - wireframes och desginskisser

## Funktioner
* Presentation av cafeet på startsidan.
* Menysida 
* Kontaktsida med kontaktuppgifter och kontaktformulär
* Javascript för mobilmenyn och formulärhantering
